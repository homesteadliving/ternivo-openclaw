# Security

Ternivo Connect uses Ternivo as the credential and policy boundary.

Do not add social-provider passwords, OAuth access tokens, refresh tokens, API secrets, or customer credentials to this repository, OpenClaw prompts, skill files, or MCP headers.

The remote MCP server is:

```
https://ternivo.app/mcp
```

Interactive authorization is handled through Ternivo OAuth and the OpenClaw MCP client flow.

Report Ternivo security issues through:
https://ternivo.app/connect/security.html
